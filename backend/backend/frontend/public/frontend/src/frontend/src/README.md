# ViraLink

ViraLink est un outil web pour transformer automatiquement des vidéos YouTube en extraits TikTok.

## Fonctionnalités
- Détection des moments viraux
- Génération automatique de sous-titres
- Recadrage vidéo au format TikTok 9:16

## Structure
- `backend/` : serveur Node.js + Express
- `frontend/` : application React
